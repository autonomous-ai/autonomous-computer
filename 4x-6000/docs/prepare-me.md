# Preparation — Mechanical & Housing

The cube arrives as a flat set of milled parts — base, fan plate, two sides, top, corner and GPU mounts, and the outer mesh panels. Print them from the [STLs](../../4x-5090/stl-models) or have them CNC'd from the [STEPs](../../4x-5090/step_models) in solid aluminium, then check the set over before anything electronic goes near it.

| No  | Step                     | Notes                                                                 |
|:---:|:-------------------------|:----------------------------------------------------------------------|
|  1  | Lay out the housing set  | Base, fan plate, sides, top, corner mounts, GPU mounts, mesh panels    |
|  2  | Inspect the milled faces | No burrs in the mesh; mating edges flat and square                     |
|  3  | Dry-fit the frame        | Base to sides to top, no fasteners yet — confirm every hole lines up   |
|  4  | Count the fittings       | Brass hex standoffs, panel screws, fan screws, GPU mount screws        |
|  5  | Stage the housing        | Base on an anti-static workbench; panels set aside until the last step |
