# Archive — CNC desktop case

The 8× 5090 was originally built into a CNC-milled, anodized aluminum desktop tower — 15.5″ × 15.5″ × 24″, 110 lb. That build has been superseded by the **5U rack chassis**; see the [current build guide](../README.md).

Everything for the old housing is kept here for reference. None of it is part of the current build.

| [`step_models/`](step_models) | 15 STEP parts for CNC machining, plus the full assembled model |
| [`stl-models/`](stl-models) | 10 printable STL versions of the same parts |

The electronics are unchanged between the two builds — the [bill of materials](../bom/bom.md) and [component checklist](../docs/prepare-ee.md) still apply, apart from the housing line.
